# Wormhole Beta-0.0.64

- Following Only now ignores the current stream game and all selected game or genre categories.
- Following Only loads every followed channel currently live before applying filters.
- Tags typed into the Twitch tag field continue to filter the followed-live results.
- Following Only can now be used while the logged-in channel is offline without selecting a previous stream.
- Offline Following Only searches skip category and viewer-range matching because no live or previous-stream baseline is available.
- Status, team, typed-tag, sorting, pagination, content-warning, and follow-back features remain available where their Twitch data is accessible.
- Raid actions remain disabled while the logged-in channel is offline.
