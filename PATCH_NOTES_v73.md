# Wormhole Patch Notes — Beta-0.0.73

- Reworked the signed-in header for narrow phones such as the OnePlus Nord N200.
- Replaced the wrapping row of account controls with a compact Menu containing theme, contrast, accessibility, and logout controls.
- Kept the Wormhole logo visible at narrow widths while preventing header overflow.
- Changed the mobile results toolbar and Find Matches controls so they no longer cover page content while scrolling.
- Improved one-column behavior for content warnings, dialogs, forms, result cards, and account controls.
- Increased phone touch targets and kept form text at a size that avoids unwanted Android browser zooming.
- Reduced embedded Twitch preview height on phones while preserving a 16:9 aspect ratio.
- Added dynamic viewport and safe-area handling for dialogs, storage choices, and phone navigation areas.
- Added automated coverage for 360-pixel phone detection and the compact account menu.
