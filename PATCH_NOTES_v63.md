# Wormhole Beta-0.0.63

- Added an embedded Twitch destination preview to the raid confirmation dialog.
- Added the same destination preview to the active 90-second raid countdown.
- Streamers can inspect the target broadcast before opening Twitch Raid Controls and using Raid Now.
- Preview playback starts muted and does not autoplay.
- Preview frames are cleared when dialogs close, raids are canceled, or the completed-raid view opens.
- Added responsive styling and accessible titles for both preview players.
- Retained the warning that Twitch ads may vary by viewer and a preview cannot guarantee that every raiding viewer is ad-free.
