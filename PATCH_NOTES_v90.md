# Wormhole Alpha-0.0.90 - Login & First Impression

Alpha-0.0.90 gives Wormhole a proper introduction before asking a streamer to connect Twitch.

## Login experience
- Rebuilt the pre-login screen as a responsive Wormhole landing experience.
- Added a plain-language explanation of what Wormhole is and why it exists.
- Added short explanations for audience-size discovery, common-interest matching, historical context, and raid discovery.
- Added a clear "No promises of growth. No magic algorithm." statement to set realistic expectations.
- Expanded the Twitch connection explanation so users know why login is needed before authorizing access.
- Added clear language that Twitch passwords are never provided to Wormhole.
- Reinforced Wormhole's privacy position with "Your data isn't the product."
- Kept accessibility, theme, and high-contrast controls available before login.
- Kept the existing Ko-fi, privacy, sponsorship, diagnostics, and Project by OneEyedNerdy footer available.
- Added a visible Alpha notice so users know the project is still actively being tested.

## Release
- Advanced Wormhole to Alpha-0.0.90.
- Advanced browser cache identifiers and versioned source entry points to v90.
- Updated the production build pipeline for the v90 source filenames and release manifest.
